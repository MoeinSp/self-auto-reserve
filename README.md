# سلف خودکار (self-auto-reserve)

ربات خرید خودکار از **سبد غذایی** سامانهٔ تغذیهٔ کالینان (`nut.uk.ac.ir`).
هر کاربر در پنل وب، تاریخ، وعده و غذاهای دلخواهش را به ترتیب اولویت وارد می‌کند. ربات سبد را
با فاصلهٔ امن چک می‌کند و به محض این‌که یکی از آن غذاها در سبد گذاشته شد، می‌خردش.

## ساختار

| فایل | کار |
|---|---|
| `app/web.py` | پنل وب (FastAPI): ثبت‌نام با کد دعوت، ذخیرهٔ رمز سامانه (رمزنگاری‌شده)، تعریف کار |
| `app/worker.py` | حلقهٔ پس‌زمینه، برای هر کاربر یک کار هم‌زمان |
| `app/cullinan.py` | ربات مرورگر (Playwright): ورود + کپچا، باز کردن سبد، انتخاب غذا، ذخیره |
| `app/ratelimit.py` | محدودیت درخواست برای این‌که حساب مسدود نشود |
| `app/captcha.py` | خواندن کپچا با OCR. اگر نشد، پنل از خود کاربر می‌خواهد واردش کند |
| `tools/dump_pages.py` | ابزار تشخیصی: صفحهٔ واقعی سبد را ذخیره می‌کند تا سلکتورها تنظیم شوند |
| `tests/` | یک سایت کالینان جعلی و تست کامل جریان خرید |

## محدودیت درخواست (پیش‌فرض‌ها در `.env`)

- هر **۲۰ ثانیه** یک دور چک (`POLL_SECONDS`، حداقل ۵) + تا ۴۰٪ تأخیر تصادفی
- بین مراحل یک دور (انتخاب تاریخ → وعده → غذا → ذخیره) **۱٫۵ ثانیه** (`STEP_SECONDS`)
- حداکثر **۵۰۰ درخواست** و **۶ تلاش ورود** در ساعت برای هر حساب
- رمز اشتباه = توقف فوری (تکرار ممکن است حساب را قفل کند)
- اگر بعد از «ذخیره» پیام خطا آمد، کار متوقف می‌شود تا دوبار خرید نشود
- با «فقط از ساعت / تا ساعت» می‌شود چک کردن را به ساعت‌های خاصی محدود کرد

مدیر پنل می‌تواند همهٔ این عددها را در `/admin` (بخش «محدودیت») بدون ری‌استارت عوض کند: سقف ساعتی را
بیشتر کند یا کامل بردارد، و فاصله‌ها را کم کند (تا ۰٫۵ ثانیه). هر کاربر هم برای هر کار می‌تواند فاصلهٔ
بررسی را تا «کمترین فاصلهٔ مجاز» پایین بیاورد. مقدارهای پایین ریسک مسدود شدن حساب را بالا می‌برند.

## مدیر پنل

اولین کسی که ثبت‌نام کند مدیر است. اگر می‌خواهی مدیر از قبل تعریف شود، `ADMIN_USERNAME` و
`ADMIN_PASSWORD` را در `.env` بگذار. نسخه‌های قبلی کاربری به اسم `admin` با رمز ثابت می‌ساختند؛
آن کاربر حالا خودکار قفل می‌شود.

## اجرا روی سرور

سرور باید به `nut.uk.ac.ir` دسترسی داشته باشد (احتمالاً یعنی سرور داخل ایران باشد).
اول روی سرور امتحان کن: `curl -I https://nut.uk.ac.ir/`

### با Docker (پیشنهادی)

```bash
git clone -b claude/quirky-allen-m13ndg https://github.com/MoeinSp/self-auto-reserve
cd self-auto-reserve
./docker.sh              # پورت پیش‌فرض 8437؛ برای تغییر: PORT=9000 ./docker.sh
```

بار اول `.env` را با `SECRET_KEY` و کد دعوت تصادفی می‌سازد، ایمیج را build و اجرا می‌کند و کد دعوت
را چاپ می‌کند. برای به‌روزرسانی: `git pull && ./docker.sh`. داده‌ها در `./data` می‌مانند.
لاگ‌ها: `docker compose logs -f`

### بدون Docker

```bash
sudo apt install -y python3-venv tesseract-ocr
python3 -m venv .venv && .venv/bin/pip install -r requirements.txt
.venv/bin/playwright install --with-deps chromium
set -a; . ./.env; set +a
.venv/bin/uvicorn app.web:app --host 127.0.0.1 --port 8000
```

### باز کردن پنل

پنل فقط روی `127.0.0.1` باز است، چون پنل بدون HTTPS رمزها را رمزنشده از شبکه رد می‌کند. برای استفادهٔ خودت:

```bash
ssh -L 8000:127.0.0.1:8000 root@SERVER   # بعد در مرورگر: http://localhost:8000
```

برای دوستانت یک دامنه + HTTPS لازم است (مثلاً Caddy با `reverse_proxy 127.0.0.1:8000`).
اولین کسی که ثبت‌نام کند به کد دعوت نیاز ندارد. پس اول خودت ثبت‌نام کن.

## تنظیم با سایت واقعی (مهم)

سلکتورهای صفحهٔ ورود از سامانهٔ کالینان دانشگاه یزد گرفته شده‌اند. جدول سبد هم از روی
اسکرین‌شات حدس زده شده. قبل از استفادهٔ واقعی، روی سرور این را اجرا کن (چیزی نمی‌خرد):

```bash
.venv/bin/python -m tools.dump_pages --date 1405/08/05
# یا با Docker:
docker compose exec -it app python -m tools.dump_pages --date 1405/08/05   # خروجی در ./dumps
```

خروجی در پوشهٔ `dumps/` ذخیره می‌شود (HTML + اسکرین‌شات + `report.txt`). رمز در آن نیست.
این پوشه را بفرست تا سلکتورها در `app/cullinan.py` (دیکشنری `SEL`) دقیق شوند.

## تست

```bash
.venv/bin/python -m unittest tests.test_flow
```

## دیپلوی با یک دستور

از کامپیوتر خودت (داخل پوشهٔ پروژه، در لینوکس/مک یا Git Bash ویندوز):

```bash
./deploy.sh root@SERVER_IP ~/.ssh/YOUR_KEY
```

کد را روی سرور در `/opt/self-auto-reserve` می‌گذارد و به‌صورت سرویس systemd اجرا می‌کند. دوباره
اجرا کردنش برنامه را به‌روز می‌کند و `.env` و داده‌ها حفظ می‌شوند. کد دعوت را در خروجی چاپ می‌کند.
لاگ‌ها: `journalctl -u self-auto-reserve -f`
